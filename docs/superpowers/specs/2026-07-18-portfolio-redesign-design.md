# 侯宇杰个人主页多页面重设计规格

## 目标

将当前单页作品集重构为适合长期维护与求职分享的多页面技术档案站。首页负责快速建立印象，工程系统、AI 工具流、技能图谱、经历与成果分别拥有独立页面，每个重点项目拥有可分享的详情地址。

## 信息架构

- `/`：首页，展示个人定位、精选工程系统、AI 工具流入口和联系方式。
- `/systems`：工程系统总览。
- `/systems/:slug`：无人机-无人船、多通道热控、聚变 VR、EmoTender 四个项目详情。
- `/ai-workflows`：AI 工具流总览。
- `/ai-workflows/:slug`：consulter、visual-article、飞书智能日历表详情。
- `/skills`：按简历原文组织的技能图谱。
- `/profile`：教育、荣誉、联系方式和作品集下载。

全站导航固定为：首页、工程系统、AI 工具流、技能图谱、经历与成果。当前页面必须有明确活动状态，所有详情页提供面包屑和相关内容入口。

## 内容边界

工程系统包含四个同级项目。EmoTender 的个人职责按用户确认写为“负责软件后端和机器人侧的全部工作”，同时保留文章中明确的完成边界：语音/文字入口、多轮对话、结构化控制、动态表情、视觉跟随、抓取与递送已经跑通，稳定连续倒液尚未完成。

AI 工具流不再使用简单外链列表。每个工具必须说明问题、工作流、实现方式、输出与证据，并链接到公开仓库或文章。公众号文章作为工具和项目的证据入口，不作为顶层导航。

技能图谱只采用 `E:\简历\Yujie_Hou_Chinese_CV.pdf` 与中文版作品集中的精确内容，不使用百分比、星级或未经证据支持的熟练度。每个技能组链接到实际使用该能力的项目。

## 页面模板

工程项目详情包含：项目结果、个人职责、背景问题、系统架构、个人贡献、技术实现、证据、完成边界、公开链接与相关项目。

AI 工具详情包含：问题、核心工作流、关键设计、产出、价值、公开证据与相关工具。

## 视觉系统

采用“工程档案 + 编辑设计”的高对比风格。浅灰白为主表面，深墨色为文字，工程蓝用于导航和主要操作，信号红用于编号与证据强调，绿色只用于已验证的技术标签。大标题使用中文宋体回退，正文使用系统黑体，技术标识使用等宽字体。

页面不使用渐变、装饰光球或卡片套卡片。层次由整宽色带、网格、编号、细线、真实项目图片和系统流程建立。动效限于 150-250ms 的页面状态与悬停反馈，并尊重 `prefers-reduced-motion`。

## 响应式与可访问性

- 在 375、390、768、1024 和 1440 像素宽度保持无横向滚动。
- 所有交互目标至少 44×44 像素。
- 保留可见键盘焦点、跳到正文链接和顺序正确的标题层级。
- 详情页桌面端使用粘性目录，移动端改为普通页内目录。
- 项目图片使用 WebP，非首屏图片懒加载并预留稳定尺寸。

## 技术方案

继续使用 React、Vite、Vitest、Testing Library 与 Lucide。引入 React Router 提供真实页面状态与浏览器历史；静态部署提供 SPA 回退文件。所有展示内容集中在结构化数据模块，页面组件只负责布局和导航。
